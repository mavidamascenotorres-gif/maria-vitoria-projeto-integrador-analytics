Trabalho de Conclusão de Curso
Autora: Maria Vitória Damasceno Torres

Objetivo
Analisar como o perfil horário típico da geração hidráulica, térmica, eólica e solar nos subsistemas do SIN mudou entre 2023 e 2025, incluindo a frequência de ocorrências atípicas.

Dados
Fonte: ONS – Dados do Balanço de Energia nos Subsistemas.

Período analisado: 01/01/2023 a 31/12/2025.

Os arquivos utilizados estão na pasta dados brutos.

Execução
O projeto foi desenvolvido em Python utilizando:
pandas
plotly

Para executar:
Manter o notebook e a pasta dados brutos na mesma pasta do projeto.
Instalar as bibliotecas necessárias.
Abrir o notebook.
Executar todas as células em sequência.
